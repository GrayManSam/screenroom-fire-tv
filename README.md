# Screenroom for Fire TV

Screenroom is a standalone TV dashboard with a remote-friendly app dock, theme controls, high contrast, optional click sounds, and live Android display diagnostics. It opens the installed MovieBox, Jellyfin, and YouTube apps. The mobile-width layout can also be previewed in a browser.

Fire OS continues to handle the physical Home button. The app requests no network permissions and uses the installed apps for playback and sign-in.
